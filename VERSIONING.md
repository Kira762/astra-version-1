# Versioning

The version tag is stored at the top of `example.client.luau` in the form `-- Version: MAJOR.MINOR.PATCH`.

For every push to `main`, increment the patch component by one before committing. For example, `0.0.1` becomes `0.0.2`, then `0.0.3` on the next push. Keep the version tag synchronized with the commit that is pushed.
